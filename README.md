# موقع الحب ❤️

موقع شخصي بسيط لحبيبتك — باسورد، خط زمني للذكريات، ألبوم صور وفيديوهات،
عداد "من يوم ما بقينا سوا"، ورسالة سرية.

## طريقة التعديل (كل حاجة في مكان واحد)

افتحي ملف [`js/config.js`](js/config.js) وغيّري فيه:

- `passwordHash` — باسورد صفحة الدخول (مش نص عادي، شرح تغييره تحت في قسم "تغيير الباسورد").
- `herName`, `startDate`, `annivDisplay` — اسمها وتاريخ بداية العلاقة (بيتحسب منه العداد).
- `heroTitle`, `heroText` — نص المقدمة.
- `musicSrc` — مكان ملف الأغنية.
- `messages` — الرسايل القصيرة.
- `reasons` — أسباب الحب (بتظهر واحدة عشوائية كل ضغطة على الزرار).
- `timeline` — الخط الزمني، كل عنصر فيه `date` و `title` و `text` و (اختياري) `photo` و/أو `video`.
- `album` — صور الألبوم (`landscape: true` للصور بالعرض).
- `videos` — فيديوهات الألبوم.
- `secretMessage` — الرسالة السرية.

مفيش داعي تلمسي `index.html` أو `app.js` أو `style.css` إلا لو عايزة تغيّري التصميم نفسه.

## تغيير الباسورد

الباسورد مش متسجل كنص عادي في الكود — متسجل كـ **hash** (كود مشفّر باتجاه واحد)،
عشان لو حد فتح الصفحة وشاف الكود (View Source) ميلاقيش الباسورد الحقيقي.

عشان تغيّريه:

1. افتحي ملف [`tools/hash-generator.html`](tools/hash-generator.html) في المتصفح (دبل كليك عليه، مش محتاج سيرفر).
2. اكتبي الباسورد الجديد، دوسي "اطلعي الكود"، وانسخي السطر اللي هيظهرلك.
3. الصقيه في `js/config.js` بدل سطر `passwordHash` الحالي.

كمان الموقع دلوقتي بيقفل الدخول 30 ثانية بعد 5 محاولات غلط متتالية، عشان
يصعّب أي حد يجرب يخمّن الباسورد بسرعة.

⚠️ **مهم تعرفيه:** أي حماية شغالة بالكامل جوه المتصفح (زي دي) مش حماية 100%
مقفولة — حد شاطر تقنيًا ممكن نظريًا ياخد الـ hash ويحاول يكسره أوفلاين، خصوصًا
لو الباسورد أرقام قليلة زي "922007". لو عايزة حماية أقوى فعليًا، استخدمي
باسورد أطول وفيه حروف وأرقام مش بس أرقام. بس للاستخدام العادي (إنك تمنعي
حد يفتح اللينك بالصدفة ويشوف محتوى شخصي)، الطريقة دي كفاية جدًا.

## إشعار على موبايلك لما حد يدخل الموقع

تقدري تخلي موبايلك يجيلك إشعار فوري لما حد يكتب الباسورد صح ويدخل الموقع،
فيه تاريخ ووقت الدخول. الطريقة دي مجانية ومش محتاجة سيرفر أو حساب، عن طريق
خدمة اسمها [ntfy.sh](https://ntfy.sh).

**الإعداد (مرة واحدة بس):**

1. نزّلي تطبيق **ntfy** على موبايلك — موجود على
   [Google Play](https://play.google.com/store/apps/details?id=io.heckel.ntfy)
   و [App Store](https://apps.apple.com/us/app/ntfy/id1625396347).
2. افتحي التطبيق ودوسي على "+" (Subscribe to topic).
3. اخترعي اسم قناة (topic) طويل وغريب وصعب حد يخمّنه، مثلاً:
   `amira-site-alerts-7f92xk` (اكتبيه بالإنجليزي/أرقام، من غير مسافات).
   اكتبيه في خانة الـ topic ودوسي Subscribe.
4. افتحي [`js/config.js`](js/config.js) وحطي نفس الاسم في `notifyTopic`:
   ```js
   notifyTopic: "amira-site-alerts-7f92xk",
   ```
5. ارفعي التعديل على GitHub. جربي تفتحي الموقع وتكتبي الباسورد الصح —
   المفروض يجيلك إشعار على موبايلك خلال ثواني.

لو سيبتي `notifyTopic` فاضية `""`، الميزة دي هتبقى متوقفة خالص ومفيش أي طلب
هيتبعت لأي حد.

⚠️ **ملحوظة مهمة:** لو الـ repo بتاعك على GitHub عام (public)، اسم القناة ده
هيبان في كود الموقع لأي حد يفتح "View Source". حد يعرف الاسم يقدر يعمل
Subscribe لنفس القناة ويشوف إشعارات الدخول برضو (أو حتى يبعت إشعارات وهمية
عليها). عشان كده اختاري اسم طويل وعشوائي فعلاً (مش حاجة زي "amira123")، ولو
عايزة خصوصية أعلى خليه سر بينك وبين نفسك ومتشاركيهوش مع حد.

## إضافة الصور والفيديوهات والأغنية

حطي الملفات هنا بنفس الأسماء اللي في `config.js` (أو غيّري المسارات في `config.js` لتطابق أسماء ملفاتك):

- الصور → فولدر `Photos/`
- الفيديوهات → فولدر `Videos/`
- الأغنية → فولدر `Musics/`

لو ملف ناقص، الموقع مش هيبوظ — هيظهر مكانه رسالة "مش موجودة" بدل ما تتكسر الصفحة.

## تشغيل الموقع محليًا

من جوه فولدر `love-site`:

```
python -m http.server 5174
```

وبعدين افتحي `http://localhost:5174` في المتصفح.

## رفع الموقع على GitHub Pages

1. اعملي repository جديد على GitHub وارفعيله محتويات فولدر `love-site`
   (الملفات تبقى في الجذر، مش جوه فولدر تاني).
2. من إعدادات الـ repo: **Settings → Pages**.
3. تحت "Build and deployment"، اختاري **Deploy from a branch**، وبعدين
   الفرع `main` والفولدر `/ (root)`، ثم **Save**.
4. استني دقيقة أو اتنين، وGitHub هيديكي لينك شكله
   `https://<username>.github.io/<repo-name>/` — ده اللينك اللي تبعتيه.

⚠️ ملحوظة: GitHub Pages المجاني بيخلي الـ repo وكل محتوياته (الكود، والصور
لو رفعتيها) قابلة للوصول لأي حد عنده اللينك أو يدور على اسم الـ repo، حتى لو
الموقع نفسه محمي بباسورد. لو مش عايزة كده، خليكي واعية إن أي حد عنده رابط
الملفات المباشر (زي `Photos/photo1.jpeg`) هيقدر يفتحه من غير ما يعدي على
صفحة الباسورد أصلاً — الباسورد بيحمي الصفحة الرئيسية بس مش الملفات نفسها.

⚠️ ملحوظة: زي ما اتشرح فوق، دي حماية "كفاية للاستخدام العادي" مش حماية عسكرية.
متحطيش في الموقع معلومات حساسة جدًا (بيانات بنكية، أرقام قومية، إلخ).
